Mock Media Server API Documentation

This API provides endpoints to manage movies, series, and songs data.

Base URL

http://localhost:3000

Endpoints

Movies

GET /movies

Get all movies

POST /movies

Add a new movie

Example request body:

{
    "title": "The Matrix",
    "director": "The Wachowskis",
    "year": 1999,
    "genre": "Sci-Fi",
    "duration": 136
}
PUT /movies/:id

Update a movie by ID

DELETE /movies/:id

Delete a movie by ID

Series

GET /series

Get all series

POST /series

Add a new series

Example request body:

{
    "title": "Breaking Bad",
    "creator": "Vince Gilligan",
    "startYear": 2008,
    "endYear": 2013,
    "genre": "Drama",
    "seasons": 5
}
PUT /series/:id

Update a series by ID

DELETE /series/:id

Delete a series by ID

Songs

GET /songs

Get all songs

POST /songs

Add a new song

Example request body:

{
    "title": "Bohemian Rhapsody",
    "artist": "Queen",
    "album": "A Night at the Opera",
    "year": 1975,
    "genre": "Rock",
    "duration": 355
}
PUT /songs/:id

Update a song by ID

DELETE /songs/:id

Delete a song by ID

Error Handling

All endpoints return appropriate HTTP status codes:

  • 200: Success
  • 201: Created (for POST requests)
  • 400: Bad Request
  • 404: Not Found
  • 500: Server Error
